# TF04_AP_Poptracker
Poptracker for the Transformers (2004)  for use with Archipelago. 

Can be used without Archipelago, using the pack settings to set goal and minicon settings.

Tracker Version 1.0.0

## Installation
This only works with the Poptracker software, available [here](https://github.com/black-sliver/PopTracker/releases).

Once you download the pack from the releases page, place it into the Poptracker `packs` folder.
